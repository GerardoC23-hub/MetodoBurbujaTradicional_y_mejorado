OrdenamientoBurbuja

Proyecto en Java para la materia de Estructura de Datos que implementa el método de ordenamiento burbuja en dos versiones: la tradicional y la mejorada con una bandera (flag).

Autor

Gerardo Cruz Hernández

Descripción

El ordenamiento burbuja compara pares de elementos vecinos de un arreglo y los intercambia si están en el orden incorrecto. Después de cada pasada, el elemento mayor de la parte no ordenada queda en su posición final.

El proyecto incluye dos métodos:

Método	Qué hace
ordenamientoBurbuja	Versión tradicional. Siempre realiza todas las pasadas.
ordenamientoBurbujaMejorado	Usa una variable booleana (bandera) para detener el proceso en cuanto una pasada completa no hace ningún intercambio, es decir, cuando el arreglo ya está ordenado.
